# Prompt Log – Calculator

## Project

Calculator Web Application

---

## Project Objective

Build a professional calculator web application using only HTML, CSS, and JavaScript. The application should support common mathematical operations, multiple input methods, theme switching, responsive design, and clean, modular code.

---

## Initial Prompts

### Prompt 1 (Plan Mode)

```text
I am planning to build a Calculator, in this Folder, using only HTML/CSS/JS as a webapp.

Requirements:

1. It should be able to do Addition, Subtraction, Multiplication, Division, Percentage, Square Root, Square, and Half.
2. It should have both Light & Dark mode, that can be changed with a toggle.
3. The calculator must work with:
   - Mouse
   - Keyboard
   - Touch Screen
4. The calculator should have a professional appearance and avoid overly bright colors.
```

### Prompt 2 (Build Mode)

```text
Now, I want you to start building the Calculator according to the plan.
```
