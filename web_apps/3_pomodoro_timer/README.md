# Pomodoro Timer

A simple Pomodoro Timer web application built using HTML, CSS, and JavaScript.

---

## Features

- Preset timer durations
- Custom timer duration
- Start, Pause, Resume, and Reset controls
- Light & Dark theme
- Responsive design
- Simple and clean user interface

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## Project Goal

This project was built to practice Vibe Coding while learning how to build interactive web applications with AI assistance.

---

## What I Learned

- JavaScript timers (`setInterval` and `clearInterval`)
- DOM manipulation
- Event handling
- Theme switching
- Responsive web design
- Managing application state

---

## Challenges

- Implementing accurate countdown logic
- Handling pause and resume functionality
- Validating custom timer input
- Synchronizing UI with timer state
- Making the layout responsive

---
