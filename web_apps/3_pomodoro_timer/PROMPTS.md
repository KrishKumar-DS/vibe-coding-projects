# Prompt Log – Pomodoro Timer

## Project

Pomodoro Timer Web Application

---

## Project Objective

Build a modern Pomodoro Timer web application using only HTML, CSS, and JavaScript. The application should include preset timer durations, custom timer support, Light & Dark themes, responsive design, and clean, maintainable code.

---

## Initial Prompts

### Prompt 1 (Plan Mode)

```text
I am building a Pomodoro Timer using HTML/CSS/JS.

Do not code yet, make a plan for it.

Requirements:
- Responsive design
- Light & Dark theme
- Preset timer durations
- Custom timer input
- Start, Pause, Resume, and Reset controls
- Clean and modern UI
- Modular JavaScript
- Meaningful variable names
- No duplicate code
```

### Prompt 2 (Build Mode)

```text
Implement the above plan.
```
